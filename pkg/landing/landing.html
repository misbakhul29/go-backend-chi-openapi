Kelebihan Menggunakan Template Ini

Arsitektur modular yang dirancang untuk stabilitas jangka panjang dan kemudahan audit kode.

01

Native Go Code Generator

Kontrak API didefinisikan murni menggunakan Go code di api/openapi/v1/, menghasilkan bundle spec YAML dan type-safe server interface secara otomatis.

02

Spec-Driven Security Engine

Autentikasi Bearer, permission RBAC (x-permission), rate-limiting (x-rate-limit), dan log audit diproses otomatis di runtime berdasarkan anotasi OpenAPI.

03

Clean Layered Architecture

Pemisahan tegas Handler, Service, dan Repository. Transaksi database context-aware didukung via db.WithTx untuk konsistensi ACID.

04

Versioned Database Migrations

Pengelolaan skema database terkontrol melalui CLI cmd/migrate (Goose engine). Menghilangkan risiko AutoMigrate di produksi, mendukung transactional lock, rollback otomatis, dan seeding peran.

05

Caching & Throttling

Redis v9 untuk sliding-window rate limiting presisi dan session blacklisting guna memitigasi serangan brute-force dan pencurian token.

06

Asynchronous Event Bus

RabbitMQ dengan durable exchange dan routing dead-letter queue (DLQ) untuk event background tak sinkron dan tamper-evident audit logs.

GETTING STARTED ↘

Dokumentasi Cara Penggunaan

Panduan langkah demi langkah menjalankan dan menguji backend di mesin lokal.

STEP 01

Generate Konfigurasi Environment (.env)

Generate file .env dan .env.example secara otomatis dari source-of-truth config/env.go: 

go run cmd/gen-env/main.go -force
STEP 02

Terapkan Migrasi Database (cmd/migrate)

Terapkan skema database terversi dan seeding peran/permission awal ke PostgreSQL:

go run cmd/migrate push

Gunakan go run cmd/migrate status untuk memeriksa status migrasi atau make <nama> untuk menambah tabel baru.

STEP 03

Jalankan Server Backend

Pastikan PostgreSQL, Redis, dan RabbitMQ sudah aktif, lalu jalankan server:

go run main.go

Server aktif pada port default :{{.Port}}. (Bisa menggunakan air untuk live-reload).

STEP 04

Buka Interactive Swagger UI

Uji dan eksplorasi seluruh rute API langsung melalui antarmuka browser:

http://localhost:{{.Port}}/api/v1/docs
STEP 05

Alur Autentikasi Contoh (Register & Login)

Daftarkan user baru dan lakukan autentikasi untuk memperoleh JWT Bearer token:

# 1. Register User Baru
curl -X POST "http://localhost:{{.Port}}/api/v1/auth/register" \
  -H "Content-Type: application/json" \
  -d '{"name":"Developer","email":"dev@example.com","password":"SecretPassword123!"}'

# 2. Login & Dapatkan Token
curl -X POST "http://localhost:{{.Port}}/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"dev@example.com","password":"SecretPassword123!"}'

# 3. Akses Protected Endpoint
curl -X GET "http://localhost:{{.Port}}/api/v1/auth/me" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"
STEP 06

Kompilasi Kontrak OpenAPI (Bila Mengubah Endpoint)

Setiap kali mengubah schema rute di api/openapi/v1/, kompilasi spec dan generate kode server Go baru:

go run cmd/gen-api/v1/main.go
